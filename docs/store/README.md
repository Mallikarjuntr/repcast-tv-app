# Appstore images

Images for the Amazon Appstore listing, generated by `tools/brand/make.mjs` (`cd tools/brand && npm install && npm run build`). Every image is drawn from the app's own palette and fonts, so they match the app.

| File | Use | Spec |
|---|---|---|
| `fire-tv-icon-1280x720.png` | Fire TV app icon | 1280 × 720 PNG, no transparency; mark, wordmark and tagline inside the 882 × 448 safe zone |
| `fire-tv-background-1920x1080.jpg` | Fire TV background image | 1920 × 1080 JPEG; the left side is kept clear for the text Fire TV draws over it |
| `icon-512.png` | Large app icon | 512 × 512 PNG |
| `icon-114.png` | Small app icon | 114 × 114 PNG |

Screenshots for the listing (1920 × 1080) are in `docs/screenshots/`.

Inside the app, the same script writes `apps/tv/assets/images/`: the launcher icon (`icon.png`, `adaptive-icon.png`), the Android TV / Fire TV launcher banner (`tv-banner.png`) and the splash (`splash.png`).
